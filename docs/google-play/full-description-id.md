# Dovra – Pembaca & Pengonversi Dokumen (deskripsi lengkap, ID)

Baca dan konversi dokumen Anda secara privat.

Dovra adalah pembaca dan pengonversi dokumen Android yang mengutamakan
privasi dan bekerja offline. Buka dokumen, pratinjau sebagai teks terstruktur
yang rapi, dan konversi ke format yang Anda butuhkan — semuanya terjadi di
perangkat Anda. File tidak pernah diunggah. Tanpa akun, tanpa iklan, tanpa
pelacakan.

## Baca dokumen Anda

- Buka TXT, Markdown, HTML, XML, RTF, DOC, DOCX, ODT, XLS, XLSX, ODS, CSV,
  TSV, PPT, PPTX, ODP, PDF, dan EPUB.
- Pratinjau terstruktur yang bersih: judul, paragraf, daftar, dan tabel.
- Buka file dari pemilih file sistem atau langsung dari aplikasi lain.
- Dovra memeriksa signature file dan memperingatkan jika isi file tidak
  sesuai dengan ekstensinya.

## Konversi yang jujur

Dovra hanya menawarkan konversi yang benar-benar didukung mesinnya,
masing-masing berlabel jelas:

- PENUH — mis. DOCX → TXT/HTML/RTF, XLSX → CSV/TSV/HTML, EPUB → TXT/HTML.
- SEDERHANA dengan catatan eksplisit — mis. DOCX → PDF (tata letak
  sederhana), spreadsheet → PDF (hanya grid tabel), presentasi → PDF/TXT
  (hanya kerangka/ekstraksi teks).

Pasangan yang tidak didukung tidak pernah muncul sebagai pilihan. Tersedia
indikator progres, pembatalan, dan pesan error yang jelas.

## Privat sejak awal

- Seluruhnya diproses di perangkat — tanpa unggah cloud, dan tanpa perlu izin internet untuk membaca atau mengonversi.
- Tanpa akun, tanpa iklan, tanpa analitik, tanpa pelacakan.
- File diakses hanya melalui Storage Access Framework Android (file dan
  folder yang Anda pilih sendiri).
- Simpan hasil dengan Save As ke folder pilihan Anda (default:
  Documents/Dovra), atau bagikan lewat share sheet sistem.
- Riwayat konversi hanya menyimpan nama, format, ukuran, dan waktu — tidak
  pernah isi dokumen. File sementara dihapus otomatis.

## Sesuai gaya Anda

- Tema Sistem / Terang / Gelap.
- Riwayat opsional di perangkat dengan hapus per item dan hapus semua.
- Gratis selamanya, dikembangkan independen. Bagian Support menautkan ke
  halaman donasi eksternal di browser Anda (opsional).

Dovra: dokumen Anda tetap di perangkat Anda.
